Car Insurance Application

Car Insurance Quote System

Developed a full-stack ASP.NET MVC web application that simulates a real-world vehicle insurance platform. The application collects customer information, including driver details, vehicle information, driving history, and coverage preferences. Based on predefined business rules, the system automatically calculates insurance premiums and generates accurate quotes. An administrative dashboard allows authorized users to view and manage all submitted insurance quotes. This project demonstrates skills in MVC architecture, database integration, form validation, and business logic implementation.

Technologies Used: ASP.NET MVC, C#, Entity Framework, SQL Server, HTML, CSS, Bootstrap
